# ANX3D — Professional Cleaning Equipment

אתר חנות למותג **ANX3D**: ידיות שאיבה, צינורות ומתאמים למכונות Sabrina, לאנשי מקצוע בתחום ניקוי הספות והריפודים.

בנוי ב-Next.js (App Router) + TypeScript + Tailwind CSS, ללא ספריות UI כבדות — כל האייקונים והאנימציות מקומיים.

## הפעלה

```bash
npm install
npm run dev      # http://localhost:3000
```

פקודות נוספות:

| פקודה | מה היא עושה |
| --- | --- |
| `npm run build` | בניית גרסת פרודקשן (כל עמודי המוצר נוצרים סטטית) |
| `npm start` | הרצת גרסת הפרודקשן שנבנתה |
| `npm run typecheck` | בדיקת טיפוסים בלבד |
| `npm run placeholders` | יצירה מחדש של כל קבצי ה-placeholder |
| `npm run export` | ייצוא סטטי מלא לתיקיית `out/` (לכל אחסון סטטי) |
| `npm run preview` | יצירת `preview.html` — קובץ אחד עצמאי עם כל האתר, לשליחה למישהו |

## מערכת ניהול לידים ועבודות (CRM)

בכתובת **`/crm`** חיה מערכת ניהול פנימית לעסק הניקיון עצמו — לידים, עבודות, יומן והכנסות. כולה בעברית (RTL) ובנויה קודם כל לטלפון:

- **ליד חדש** — כפתור מרכזי בתחתית המסך. שם, טלפון, כתובת, עיר, תאריך ושעה, סוגי שירות (בחירה מרובה), מחיר, הערות ומקור הליד (Google / Facebook / Instagram / WhatsApp / אחר).
- **סטטוסים** — חדש, ממתין לאישור, נקבע, בדרך ללקוח, הושלם, בוטל — עם סימון צבעוני על כל כרטיס.
- **מסך ראשי** — עבודות היום ומחר ככרטיסים (שעה, שם, עיר, שירות, מחיר, סטטוס) + הכנסות היום והחודש.
- **יומן** — תצוגה יומית, שבועית וחודשית; לחיצה על תאריך מציגה את עבודות היום.
- **עמוד לקוח** — כל הפרטים + כפתורי פעולה מהירים: WhatsApp, התקשר, Waze (ניווט ישיר לכתובת), ערוך, סמן כהושלם, בטל עבודה, וכן היסטוריית עבודות קודמות של אותו לקוח (לפי מספר טלפון).
- **חיפוש** — לפי שם, טלפון, כתובת או עיר.
- **סטטיסטיקות** — הכנסה חודשית, מספר עבודות, עבודה ממוצעת, כמות לידים, אחוז המרה, השירותים והמקורות המובילים.

### הקמה

1. הריצו את `supabase/crm-schema.sql` ב-SQL Editor של פרויקט ה-Supabase (בנוסף ל-`schema.sql` של החנות). הטבלה `leads` נעולה ב-Row Level Security — רק משתמש מחובר קורא או כותב.
2. ודאו ש-`.env.local` מכיל את `NEXT_PUBLIC_SUPABASE_URL` ו-`NEXT_PUBLIC_SUPABASE_ANON_KEY` (ראו `.env.example`).
3. צרו משתמש מנהל ב-Supabase (**Authentication → Users → Add user**) — אותו חשבון משמש גם את פאנל הניהול של החנות וגם את ה-CRM.
4. היכנסו ב-`/crm/login`.

### חיבור להוצאות הפרסום בפייסבוק (רשות)

בעמוד הסטטיסטיקות אפשר לחבר את חשבון ה-Ads Manager ולראות את הוצאות הפרסום של היום, החודש והשנה, כולל יחס החזר מול ההכנסות:

1. הריצו שוב את `supabase/crm-schema.sql` (נוספה טבלת `crm_settings` — הקובץ בטוח להרצה חוזרת).
2. באפליקציה: **נתונים ← הוצאות פרסום — פייסבוק** ← הזינו מזהה חשבון מודעות ו-Access Token עם הרשאת `ads_read` (מדריך קצר מופיע שם בטופס).

הטוקן נשמר בטבלה שמוגנת ב-RLS — רק מנהל מחובר יכול לקרוא אותו, והדפדפן פונה ל-Graph API ישירות.

### התקנה על הטלפון (PWA)

האפליקציה מוגדרת כ-PWA שנפתחת ישר אל `/crm` במסך מלא:

- **iPhone (Safari):** פתחו את `/crm` → כפתור שיתוף → **הוספה למסך הבית**.
- **Android (Chrome):** פתחו את `/crm` → תפריט ⋮ → **הוספה למסך הבית / התקנת אפליקציה**.

שימו לב: ה-CRM דורש שרת (Vercel וכדומה) — הוא לא נכלל בייצוא הסטטי כי הנתונים נטענים מ-Supabase בזמן אמת.

## מסחר יומי אוטומטי (`/trading`)

בכתובת **`/trading`** חיה מערכת מסחר אוטומטית: היא סורקת את המניות "החמות" של היום בבורסה האמריקאית, קונה את החזקות שבהן, ומוכרת **באותו יום** — או ברווח/בהפסד מוגדר מראש, או בכל מקרה לפני סגירת השוק. שום פוזיציה לא נשארת ללילה.

> **אזהרה:** מסחר יומי הוא פעילות בסיכון גבוה ורוב הסוחרים היומיים מפסידים כסף. המערכת אינה ייעוץ השקעות. ברירת המחדל היא **חשבון דמו (Paper)** עם כסף וירטואלי — מומלץ מאוד לרוץ כך תקופה ארוכה לפני שמתקרבים לכסף אמיתי.

### איך זה עובד

1. **סריקה** — כל כמה דקות המנוע מושך משרתי Alpaca את רשימת העולות החזקות של היום ואת המניות הנסחרות בנפח הגבוה ביותר.
2. **סינון** — נשארות רק מניות במחיר 3–100 דולר, שעלו לפחות 3% היום, עם מחזור של 5M$ לפחות, שעדיין מעל מחיר הפתיחה וקרובות לשיא היומי (מומנטום שלא דעך). מניות שכבר נקנו היום לא ייקנו שוב.
3. **קנייה** — עד 3 פוזיציות במקביל, כ-10% מההון לכל אחת (עד 2,000$). כל קנייה נשלחת כפקודת **Bracket**: טייק-פרופיט של ‎+4% וסטופ-לוס של ‎−2% שמנוהלים על שרתי הברוקר — היציאה מתבצעת גם אם האתר שלכם למטה.
4. **הגנה יומית** — הפסד של 3% מההון ביום אחד עוצר את המסחר ומחסל את כל הפוזיציות עד מחר.
5. **סוף יום** — ב-15:50 שעון ניו-יורק הכל נסגר אוטומטית. מסחר יומי בלבד.

כל המספרים ניתנים לכוונון דרך משתני סביבה — ראו `.env.example`.

### הקמה

1. פתחו חשבון חינמי ב-[alpaca.markets](https://alpaca.markets) (ברוקר אמריקאי עם API). בדשבורד של Alpaca, במצב **Paper**, צרו API Key.
2. הגדירו ב-`.env.local` (ובהגדרות הסביבה של Vercel): `ALPACA_KEY_ID`, `ALPACA_SECRET_KEY`, ו-`TRADING_API_SECRET` (סיסמה שתמציאו — היא שער הכניסה לדשבורד).
3. היכנסו ל-`/trading` והזינו את הטוקן. תראו את החשבון, הפוזיציות והעסקאות של היום, וכפתור חירום **"מכור הכל עכשיו"**.

### מי מפעיל את המנוע?

המנוע רץ ב"פעימות" — כל קריאה ל-`/api/trading/tick` מבצעת מחזור אחד (סריקה → קנייה → ניהול → סגירה). צריך משהו שיקרא לו כל כמה דקות בשעות המסחר:

- **Vercel Cron** — קובץ `vercel.json` כבר מגדיר פעימה כל 5 דקות בשעות המסחר. בתוכנית ה-Pro זה עובד כמו שהוא (הגדירו גם `CRON_SECRET` בהגדרות הסביבה); בתוכנית החינמית Vercel מוגבל לפעם ביום, אז השתמשו באחת החלופות.
- **שירות Cron חיצוני** (למשל cron-job.org, חינם) — כוונו אותו ל-`https://האתר-שלכם/api/trading/tick` כל 5 דקות, ימים ב׳–ו׳ 16:30–23:00 שעון ישראל, עם כותרת `Authorization: Bearer <TRADING_API_SECRET>`.
- **מקומית** — `npm run trader` מריץ לולאה שקוראת לפעימה כל דקה (ברירת מחדל מול `localhost:3000`; הגדירו `TRADER_URL` בשביל האתר החי).

פעימות מיותרות לא מזיקות: כשהשוק סגור או שאין מה לעשות, הפעימה פשוט לא עושה כלום.

### מעבר לכסף אמיתי

רק אחרי תקופה מוצלחת בדמו, ובזהירות: הגדירו `ALPACA_PAPER=false` **וגם** `ALPACA_ALLOW_LIVE=I_UNDERSTAND_THE_RISKS` (בלי שניהם המנוע מסרב לגעת בחשבון אמיתי), וכן `TRADING_API_SECRET` חזק — במצב אמיתי המערכת מסרבת לעבוד בלעדיו. שימו לב לכלל ה-PDT האמריקאי: מסחר יומי בחשבון אמיתי עם פחות מ-25,000$ מוגבל בחוק למספר עסקאות יומיות בשבוע.

## העלאה לאוויר

הדרך הפשוטה ביותר היא Vercel (החברה שמפתחת את Next.js), בחינם:

1. היכנסו ל-[vercel.com](https://vercel.com) והתחברו עם חשבון GitHub.
2. **Add New → Project**, ובחרו את המאגר `ANX-`.
3. בשדה הענף בחרו את הענף שבו נמצא הקוד.
4. **Deploy** — Vercel מזהה Next.js לבד, אין מה להגדיר.

תוך כדקה מתקבלת כתובת חיה. כל דחיפה ל-GitHub מעדכנת את האתר אוטומטית. אפשר לחבר דומיין משלכם דרך **Settings → Domains**.

לחלופין, `npm run export` מייצר אתר סטטי בתיקיית `out/` שאפשר להעלות לכל אחסון (Netlify, Cloudflare Pages, או אפילו FTP רגיל).

## החלפת התמונות בתמונות אמיתיות

כל התמונות באתר הן **placeholders ממוספרים** — לא תמונות סטוק. כל אחד מהם מציג את מספר התמונה בגלריה ואת שם המוצר, כדי שיהיה ברור איזו תמונה אמיתית מחליפה איזה קובץ.

**תמונות מוצר** — לכל מוצר שלוש תמונות תחת `public/products/<slug>/`:

```
public/products/anx-pro-handle/1.svg   ← התמונה הראשית (מופיעה גם בכרטיס המוצר)
public/products/anx-pro-handle/2.svg
public/products/anx-pro-handle/3.svg
```

להחלפה: שימו את הקובץ האמיתי באותה תיקייה (למשל `1.jpg`) ועדכנו את הנתיב במערך `images` של המוצר ב-`src/lib/products.ts`. מומלץ יחס 1:1 (ריבוע), לפחות 1000×1000.

**תמונת OG לשיתופים** — נוצרת אוטומטית כ-PNG ב-`src/app/opengraph-image.tsx`. אפשר להחליף אותה בקובץ תמונה קבוע.

**Favicon** — `src/app/icon.svg`.

> אחרי שמחליפים קובץ SVG בקובץ JPG/PNG אפשר להסיר את הדגל `dangerouslyAllowSVG` מ-`next.config.mjs`. הוא נדרש רק כדי ש-`next/image` יטען את ה-placeholders שהם SVG.

## הזמנות ב-WhatsApp

כל כפתור הזמנה פותח קישור בפורמט:

```
https://wa.me/972535257250?text=<הודעה מקודדת>
```

ההודעה נבנית ב-`src/lib/site.ts` דרך `encodeURIComponent`, כך שהעברית עוברת תקין בכל המכשירים. שינוי המספר במקום אחד (`site.whatsappNumber`) מתעדכן בכל האתר.

## הערות טכניות

- **RTL מלא**: הפריסה משתמשת ב-logical properties (`ps-`, `me-`, `start-`) כך שהיישור, האייקונים והניווט מתהפכים נכון.
- **Mobile first**: כל הפריסות נבנו קודם למובייל ומתרחבות מעלה.
- **ביצועים**: `next/image` עם `sizes` מדויק, lazy loading לתמונות המוצרים, ופונט Heebo עם `display: swap`.
- **נגישות**: קישור דילוג לתוכן, `alt` לכל התמונות, פוקוס נראה למקלדת, וסינון המוצרים ממומש כ-`radiogroup`.
- **SEO**: title/description לכל עמוד, Open Graph ו-Twitter cards, `sitemap.xml`, `robots.txt` ו-JSON-LD (Product, Store).

לפני עלייה לאוויר כדאי להגדיר את כתובת האתר האמיתית:

```bash
NEXT_PUBLIC_SITE_URL=https://anx3d.co.il
```
