# ערוץ טלגרם "סקידקי" — מערכת אוטופיילוט

מערכת לניהול ערוץ טלגרם ברוסית על דילים וצרכנות חכמה בישראל:

1. **סורקת מקורות** — ערוצי טלגרם ציבוריים (דרך דף התצוגה `t.me/s/...`, בלי צורך בחשבון) ופידים של RSS.
2. **מנסחת ברוסית עם AI** — כל פריט חדש עובר ל־Claude שמנסח אותו כפוסט בסגנון הערוץ (הסגנון מוגדר ב־`config.js` וניתן לכיוון).
3. **שולחת אליך לאישור** — כל טיוטה מגיעה אליך לצ'אט הפרטי עם הבוט, עם כפתורי ✅ פרסום / ❌ דילוג. שום דבר לא מתפרסם בלי אישור שלך.
4. **מפרסמת לערוץ** בלחיצת כפתור.

אין תלויות npm — Node 20.6+ בלבד.

---

## הקמה (כ־15 דקות, פעם אחת)

### שלב 1 — פתיחת הערוץ (רק אתה יכול, דורש חשבון טלגרם)

1. בטלגרם: תפריט → **New Channel**.
2. שם ברוסית, למשל: `Скидки Израиль | Умный шопинг` (השם ניתן לשינוי בכל רגע).
3. סוג: **Public**, ובחר כתובת קצרה וזכירה (למשל `il_skidki_smart`).
4. תיאור לדוגמה: `Скидки, акции и умное потребление в Израиле. Каждый день — только проверенные предложения.`

### שלב 2 — יצירת הבוט

1. פתח צ'אט עם **@BotFather** → `/newbot` → תן שם וכתובת (למשל `il_skidki_editor_bot`).
2. שמור את ה־**token** שתקבל.
3. הוסף את הבוט **כמנהל בערוץ** (Channel → Administrators → Add Admin) עם הרשאת Post Messages.

### שלב 3 — הגדרה והרצה

```bash
cd channel-bot
cp .env.example .env   # ומלא את הערכים
```

- `TELEGRAM_ADMIN_CHAT_ID`: שלח הודעה ל־**@userinfobot** בטלגרם — הוא יחזיר את המספר שלך.
- `ANTHROPIC_API_KEY`: מ־console.anthropic.com (עלות שוטפת: אגורות בודדות לפוסט).
- פתח את `config.js` והוסף מקורות ברשימת `sources` — ערוצי דילים ציבוריים שאתה עוקב אחריהם ופידים רלוונטיים.

```bash
npm run fetch-once   # ריצת בדיקה: סבב איסוף אחד + האזנה לכפתורים
npm start            # ריצה מלאה: איסוף כל 30 דק' + האזנה
```

### שלב 4 — הרצה קבועה

השרת צריך לרוץ ברציפות. אפשרויות זולות:
- **Railway / Render / Fly.io** — שירות worker קטן (חינם עד ~5$/חודש).
- כל VPS (Hetzner ~4€/חודש) עם `systemd` או `pm2`.

## איך מגייסים קהל (מה שבאמת עובד)

**מה לא עושים:** אין להוסיף אנשים ידנית/אוטומטית לערוץ ואין לקנות "מנויים". זה מוביל לחסימת הערוץ על ידי טלגרם, והמנויים האלה ממילא מתים — הם הורסים את יחס הצפיות שקובע כמה מפרסמים ישלמו לך.

**מה כן, לפי סדר:**

1. **שבועיים של תוכן לפני שיווק.** ערוץ ריק לא ממיר. 3–5 פוסטים ביום (המערכת עושה את רוב העבודה) עד שיש ~30 פוסטים בעמוד.
2. **פרסום ממומן בערוצי טלגרם קיימים** של דוברי רוסית בישראל (חדשות, ערי מגורים, קבוצות עולים). פוסט בערוץ בינוני עולה ₪200–800 ומביא בדרך כלל 100–600 מנויים אם הערוץ שלך נראה חי. מתחילים בקטן, מודדים עלות־למנוי, ומגדילים רק מה שעובד.
3. **חילופי פרסום (взаимопиар)** עם ערוצים בגודל דומה — חינם, וזה המנוע המרכזי של צמיחת ערוצים ברוסית.
4. **קבוצות פייסבוק של עולים** ("Русскоязычный Израиль" וכד') — לשתף דיל חם ספציפי עם קרדיט לערוץ, לא ספאם של לינק.
5. **הפניה מהעסק הקיים:** לינק לערוץ בכל חבילה של ANX3D, בחתימת מייל, בדף התודה בחנות.

**מוניטיזציה בהמשך** (מ~5,000 מנויים): לינקים שותפים (Admitad, AliExpress, בוקינג), פוסטים ממומנים, ובהמשך ערוץ פרימיום בתשלום.

## מבנה הקוד

```
channel-bot/
  index.js            — לולאה ראשית: איסוף, אישורים, פקודות
  config.js           — מקורות, סגנון עריכה, תדירות
  src/fetchSources.js — סריקת t.me/s/ ו־RSS
  src/rewrite.js      — ניסוח הפוסט ברוסית (Anthropic API)
  src/telegram.js     — Telegram Bot API (long polling)
  src/store.js        — דדופליקציה וטיוטות (קובץ JSON)
  data/state.json     — נוצר אוטומטית, לא בגיט
```
