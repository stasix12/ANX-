# Site Factory — סוכנות אתרים לעסקים דוברי רוסית

מערכת לייצור אתרי תדמית ("визитка") לעסקים קטנים: ממלאים קובץ פרטים אחד — מקבלים אתר מוכן לפרסום. זה המוצר שאתה מוכר; הקובץ הזה הוא גם מדריך ההפעלה העסקי.

---

## איך מייצרים אתר (5 דקות לאתר)

```bash
cd site-factory
cp clients/demo.json clients/<שם-לקוח>.json   # ולערוך את הפרטים
node generate.js clients/<שם-לקוח>.json        # → dist/<slug>/
```

הקובץ מגדיר הכל: שם, תיאור, שירותים ומחירים, טלפון/וואטסאפ, כתובת (מפה נכנסת אוטומטית), שעות, ביקורות, צבעים, תמונות (שים בתיקייה `clients/<slug>/` והפנה אליהן ב־`gallery`/`heroImage`), ושורת עברית לפוטר.

**פרסום:** גרור את `dist/<slug>/` ל־[Netlify Drop](https://app.netlify.com/drop) (חינם, שניות) או חבר ל־Vercel. דומיין `.co.il`/`.com` — ₪40–60 לשנה, וזה מה שהלקוח משלם עליו "אחזקה".

## התמחור

| חבילה | מה כלול | מחיר |
|---|---|---|
| בסיס | אתר עמוד אחד ברוסית, וואטסאפ, מפה, עד 6 שירותים | ₪1,500 |
| סטנדרט | + גלריה, ביקורות, דומיין אישי, כפתורי רשתות | ₪2,200 |
| פרימיום | + גרסה בעברית, טופס פניות, חיבור לאינסטגרם | ₪3,000–3,500 |
| אחזקה חודשית | דומיין, אחסון, עד 2 עדכוני תוכן בחודש | ₪80–120/חודש |

האחזקה היא הזהב: 20 לקוחות × ₪100 = ₪2,000/חודש קבועים בלי עבודה כמעט. תמיד למכור אותה יחד עם האתר ("המחיר כולל שנה ראשונה" ואז חידוש).

## איפה מוצאים לקוחות

1. **קבוצות פייסבוק/טלגרם של דוברי רוסית** (ערים, "мамы Израиля", עולים): כל מי שמפרסם שם שירות בלי אתר — ליד. 15–20 פניות ביום לוקחות חצי שעה.
2. **אינסטגרם**: עסקים עם עמוד פעיל ובלי לינק לאתר בביו.
3. **הדגמה במקום מכירה** — הנשק הסודי: לפני הפנייה, מלא את ה־JSON מפרטים שהעסק כבר פרסם, ייצר אתר, העלה ל־Netlify, ושלח לו **לינק לאתר מוכן שלו**. "עשיתי לך דמו, ככה ייראה האתר שלך" ממיר פי כמה מ"רוצה אתר?". עלות ההכנה: 10 דקות.
4. **המלצות**: מהלקוח השלישי והלאה — ₪200 על כל לקוח שהוא מביא.

## תסריט פנייה (ברוסית, מוכן להעתקה)

> Здравствуйте, [имя]! Видел(а) вашу страницу в [группе] — отличные работы 👍
> Я делаю сайты-визитки для мастеров и малого бизнеса: страница с услугами, ценами, кнопкой WhatsApp и картой — клиенты записываются сами, даже когда вы заняты.
> Я уже собрал(а) для вас пример — вот как может выглядеть ваш сайт: [ссылка на демо]
> Если нравится — готовый сайт со всеми вашими данными будет за 2 дня. Стоимость ₪1,500 разово.

תשובות להתנגדויות נפוצות:
- *"יש לי אינסטגרם"* → «Инстаграм — отлично, но в поиске Google вас не находят, и цены/запись клиенту приходится выпрашивать в директе. Сайт работает 24/7 и даёт кнопку записи в один клик.»
- *"יקר"* → «Это разовая оплата — меньше, чем вы платите за день рекламы. Сайт остаётся вашим навсегда.»

## תהליך העבודה מול לקוח (צ'קליסט)

1. תשלום מקדמה 50% (ביט/העברה) — לא מתחילים בלי.
2. לאסוף בוואטסאפ: לוגו/שם, תיאור קצר, רשימת שירותים+מחירים, טלפון, כתובת, שעות, 5–10 תמונות, 2–3 המלצות מלקוחות, צבעים מועדפים.
3. למלא JSON, לייצר, להעלות לדומיין זמני, לשלוח לאישור.
4. סבב תיקונים אחד כלול (לתחום מראש!), חיבור דומיין, יתרת תשלום, מסירה.
5. שבוע אחרי: הודעת "איך הולך?" + הצעת אחזקה/שדרוג (עברית, בוט וואטסאפ).

## יעדים ריאליים

- שבוע 1: אתר פורטפוליו לעצמך + 3 דמו־אתרים לנישות שונות (קוסמטיקאית, מוסך, מורה) + 50 פניות ⇒ עסקה–שתיים ראשונות.
- חודש 1: 4–6 לקוחות ⇒ ₪7,000–12,000.
- חודש 3: 15+ לקוחות, הכנסת אחזקה ₪1,500+/חודש, ומתחילים למכור שדרוגים (בוט וואטסאפ — ראה `channel-bot/` כבסיס) ללקוחות קיימים.

## מבנה

```
site-factory/
  generate.js       — המחולל (כולל התבנית והעיצוב)
  clients/*.json    — קובץ הגדרות לכל לקוח
  clients/<slug>/   — תמונות של הלקוח (אופציונלי)
  dist/<slug>/      — האתרים המיוצרים (לא בגיט)
```
